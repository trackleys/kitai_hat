# ChinaHat (Fabric 1.21.11)

Китайская шляпа над твоей головой. Настройки в игре: клавиша **H**
(Управление → категория «ChinaHat»): цвет RGB, размер, вкл/выкл.
Настройки сохраняются в `config/chinahat.json`.

## Сборка через GitHub Actions
Загрузи файлы репозитория на GitHub — workflow `.github/workflows/build.yml`
соберёт jar автоматически. Готовый мод: Artifacts → `chinahat` → jar из zip.

Клиентский мод, рендер стандартный — совместим с VulkanMod.
